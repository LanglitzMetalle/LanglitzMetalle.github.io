# METALXACT – Produktzugang und Online-Werkzeuge

Dieses Projekt bündelt den Einstieg in das METALXACT Sortiment, den Metallgewicht-Rechner und Informationen zur Pulverbeschichtung. Der Produktkatalog auf GitHub Pages dient der Navigation; Produktvarianten, Maße, Preise und Verfügbarkeit werden auf den jeweils verlinkten METALXACT Shopseiten angezeigt.

## Metallgewicht-Rechner

Der Rechner schätzt die theoretische Masse ausgewählter Halbzeuge aus Form, Abmessungen und Material-Richtwert. Das Ergebnis ersetzt keine Wägung, Werkstoffprüfung oder Freigabe. Für Konstruktion, Einkauf und Nachweise sind die konkrete Legierung, der Lieferzustand, die tatsächlichen Maße und die Produkttoleranzen maßgeblich.

## Hinweise zum Sortiment

Die Übersichten verlinken zu öffentlich sichtbaren Produktgruppen. Maßgeblich für die aktuelle Auswahl sind die jeweilige METALXACT Shopseite und die dort angezeigte Konfiguration. Bei technischen Fragen sollte die konkrete Produkt- und Werkstoffdokumentation geprüft werden.
